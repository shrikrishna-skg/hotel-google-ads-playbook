# Team visuals

The included SVG diagrams are original explanatory illustrations, not Google Ads screenshots and not hotel photographs. Their text is editable; they request Calibri and fall back to a system sans-serif font.

- [booking-workflow.svg](booking-workflow.svg): the campaign-to-booking operating sequence.

## Add an approved image

Upload a sanitized PNG/JPG/SVG here using GitHub's **Add file → Upload files**, then reference it in Markdown:

```markdown
![Describe the setting and what the image establishes](../assets/your-image.png)
```

Add a caption with capture date, source, usage permission and whether it is an illustration, preview or saved-state evidence. Use relative links appropriate to the document's folder.

For hotel photography, obtain rights for **public repository distribution**, not just paid-ad use. Do not copy OTA photographs or assume a publicly visible hotel photo is freely reusable. For screenshots, remove account IDs, email addresses, payment details, private URLs, other client names and browser tabs. Inspect the final image pixels and file metadata before submitting.
