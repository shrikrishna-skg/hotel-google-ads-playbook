# Contributing

Read [the playbook](docs/PLAYBOOK.md), then propose one clear improvement at a time.

1. Open a document on GitHub and choose the pencil/Edit control. Without write access, fork the repository and propose the edit through a pull request.
2. Explain the problem, the change and the evidence in the pull request. Use the included [template](.github/pull_request_template.md).
3. Preview Markdown, open every changed link, inspect images and remove confidential information.
4. Ask the repository owner to review and merge. A public repository is readable by everyone; it is not editable by everyone.

Use the blank templates in a **private working location** for real hotel data. Add only approved, sanitized examples to this public repository. Never place account screenshots, guest records, login tokens or internal document links in issues or pull requests.

For images, follow [assets/README.md](assets/README.md). Keep original diagrams simple and editable. Prefer documentation and native platform controls to new automation. This repository needs no application framework or dependency installation.

When updating policy guidance, add a current official source and the date checked. Label judgment, examples, forecasts and observed results accurately. No fixed booking or ranking promises.
